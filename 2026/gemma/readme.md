## notes on ai model,
If you want the absolute lowest friction path that keeps your current VS Code window exactly as it is right now, do this:

Open your VS Code extensions marketplace and install Roo Code.

Go to OpenRouter.ai, put $10 into your balance, and generate an API key.

Select "OpenRouter" in the Roo Code dropdown menu, paste your key, and select a cheaper model like deepseek/deepseek-chat (costs fractions of a penny) for general coding, then swap to anthropic/claude-3.5-sonnet only when you need heavy logic solved.
